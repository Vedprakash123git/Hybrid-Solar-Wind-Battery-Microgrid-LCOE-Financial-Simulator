# Hybrid-Solar-Wind-Battery-Microgrid-LCOE-Financial-Simulator
uilt an end-to-end Python simulator that models a hybrid renewable microgrid — solar PV, wind, and battery storage — at hourly resolution over a full year, then evaluates its financial viability using standard project-finance metrics: Levelized Cost of Energy (LCOE), Net Present Value (NPV), and Internal Rate of Return (IRR)
